# 西欧中世纪（Medieval Western Europe）

## 身份与范围

- Canonical ID：`europe/medieval-western-europe`
- 单元类型：跨地区历史时期；约500–1500年。
- 默认值：12–13世纪法兰西或英格兰普通城镇；支持等级 `baseline`。
- 必须细化：地区和世纪；早期、盛期、晚期中世纪的服饰、建筑、武备与城市差异很大。

## 同时代视觉证据与场景路由

- 默认古画模式：`period-artwork translation`，但只有在地区和世纪明确后才能选择彩饰手稿、壁画、刺绣、彩色玻璃、祭坛画或其他媒介；若仍是宽泛“中世纪”，先澄清，不生成统一画风。
- 写实请求使用 `reconstructed realism`，以考古、服饰、建筑和文献证据控制内容，不添加羊皮纸、金地或手稿边框。
- 证据边界：宗教手稿、祭坛画和教堂艺术偏神学、赞助与仪式；可提取线条、色块、空间、人物尺度和页面结构，不能把光环、圣徒姿势、金地或贵族纹章推广给普通市场。

- 城镇 / 市场：木框架或石木建筑、摊棚、泥土 / 石铺道路、教堂与城墙按当地条件安排；采用彩饰手稿或克制考古插图。
- 家庭 / 农业：低矮木石住宅、壁炉、木桌凳、陶器、篮筐、纺织与农具；减少宫廷金彩。
- 宗教 / 朝圣：罗曼式或哥特式建筑必须与世纪和地区匹配；彩色玻璃与圣物只在相应语境出现。
- 武装人物：11–13世纪以锁子甲等为主；完整板甲主要属于更晚阶段，非战斗场景不加全套甲胄。

## 服饰、建筑与器物

- 以 linen undergarment、wool tunic / gown、hose、cloak、hood 和皮鞋为基础，轮廓按世纪调整。
- 普通城镇使用木框架、石、灰泥、茅草或瓦 / 木瓦屋面；城堡与教堂不代表所有建筑。
- 使用马、牛车、手推车、木桌凳、陶 / 木 / 金属器皿、蜡板、羊皮纸、油灯和蜡烛。

## 常用替换

| 现代元素 | 历史对应物 | 条件 |
|---|---|---|
| 汽车 / 自行车 | horse, ox cart, handcart or walking traveler | 按身份和载货功能 |
| 手机 | wax tablet, folded parchment letter, rosary, purse, or corrected hand | 按动作语义选择 |
| 路灯 / 霓虹 | torch, candle lantern, shop awning or remove | 夜景保持低照度 |
| 玻璃幕墙 | timber-frame, stone-and-plaster houses and workshop fronts | 地区与世纪决定材质 |

## 禁用与来源

- 禁止把维京、十字军、哥特板甲、都铎服装和文艺复兴街道混在一个无年代场景；禁止奇幻尖塔海。
