# 宋代（Song Dynasty）

## 时代特征

素雅精致、文人意趣、重意境与留白；工笔花鸟与界画（界面画）高度成熟；市井长卷风俗画兴起。

## 画风关键词（英文进提示词，中文标注含义）

| 关键词 | 含义 |
|---|---|
| gongbi (工笔) | 工细设色，笔法精致 |
| ink and color on silk (绢本设色) | 绢底、矿物颜料设色 |
| fine-line brushwork (精细白描) | 细线勾勒 |
| jiehua (界画) | 用界尺画建筑/舟车的工整画法 |
| literati aesthetic (文人画意趣) | 素雅、写意、重意境 |
| shan shui (山水) | 山水画 |
| subdued mineral pigments (赭石花青) | 赭石、花青、淡墨的素雅配色 |
| negative space (留白) | 大量留白 |
| thin gold script (瘦金体) | 宋徽宗瘦金体（题款文字） |

## 参考画家 / 作品

- 市井长卷 / 多人街景：张择端《清明上河图》
- 山水：王希孟《千里江山图》、范宽《溪山行旅图》、马远、夏圭（马一角夏半边）
- 花鸟：崔白《双喜图》、宋徽宗赵佶
- 人物 / 仕女：李唐、苏汉臣《秋庭戏婴图》
