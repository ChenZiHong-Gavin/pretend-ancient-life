# 秦代（Qin Dynasty）

## 身份与范围

- Canonical ID：`china/qin`
- 单元类型：统一帝国；前221–前206年。
- 默认值：关中咸阳周边的道路、官府或普通出行；支持等级 `baseline`。
- 证据边界：兵马俑和帝陵材料极强但高度特殊，不能把所有秦代人物都画成陶俑军队。

## 同时代视觉证据与场景路由

- 默认模式：日常、道路和官府题材优先 `reconstructed realism`；古画请求使用基于秦代出土图像与彩绘遗存的 `creative interpretation`，明确不存在可直接套用的成熟传世秦画体系。
- 同时代视觉锚点：兵马俑原有彩绘、帝陵与墓葬材料、瓦当和器物纹样、简牍与出土线刻。只提取轮廓、用色、人物类型和表面材质，不把陶俑姿态或军阵推广给普通生活。
- 成熟汉墓壁画和画像石只能作为邻近比较，不能不加说明地冒充秦代画风。

- 军事 / 仪仗：根据兵马俑区分军吏、步兵、弩手和御手；保留土、漆和彩绘残留的物质感。
- 官府 / 交通：夯土城墙、木构厅堂、标准化道路、驿传与木制车乘，强调早期帝国行政秩序。
- 日常 / 农业：采用战国晚期到秦汉之际的陶器、木器、漆器和简牍，画面保持朴素。
- 艺术化输出：采用考古纪实绘画，或以出土线刻、陶俑彩绘和器物纹样为依据的淡设色创作。

## 服饰、建筑与器物

- 服饰使用交领袍服、上衣下裳、束带、发髻或帻的早期形式；军装按俑的铠甲等级区分。
- 建筑使用夯土台基、木构宫室、院落、土石道路与朴素瓦件；避免后世斗拱彩画和高耸飞檐。
- 使用木车、马车、弩、戈、剑、陶器、漆器、竹木简与印章。

## 常用替换

| 现代元素 | 历史对应物 | 条件 |
|---|---|---|
| 汽车 / 卡车 | horse-drawn carriage, ox cart, baggage wagon | 按载人与载货功能选择 |
| 公路 | broad packed-earth imperial road with drainage | 保留消失点，不保留车道漆线 |
| 手机 / 证件 | bamboo-slip document, wooden tally, seal token | 按通信或行政功能 |
| 混凝土建筑 | rammed-earth compound with timber halls and tiled roofs | 保持体量但降低层数 |

## 禁用与来源

- 禁止把兵马俑的陶土质感复制到活人皮肤；禁止汉代画像石、唐代甲胄和长城旅游景观混入。
