# 元代（Yuan Dynasty）

## 范围与默认值

- 时间范围：1271–1368年。
- 默认子时期：十四世纪前半叶，适合行旅、草原、农业和大都城市题材。
- 默认地域：北方草原或大都；江南文人山水应单独选择。
- 适用场景：骑行、狩猎、驿路、草原营地、多族群城市、农耕和隐逸山水。

## 视觉特征

根据场景在两条传统中择一：草原、狩猎和宫廷行旅使用细线与淡设色的纪实手卷；江南山水使用纸本水墨和书法性笔触。元代画面可体现蒙古统治下多族群并存，但不要把所有中国城市变成草原营地，也不要把普通骑手画成重甲战士。

## 场景路由

| 场景 | 推荐媒介与视觉语法 | 参考作品 |
|---|---|---|
| 草原 / 骑行 / 狩猎 | Yuan court handscroll, fine ink outline and restrained color | 刘贯道《元世祖出猎图》传统 |
| 城市 / 商旅 | documentary ink and color on silk；蒙古与汉地服饰并存 | 大都与驿站题材 |
| 农业 / 村庄 | Song-derived narrative handscroll | 《耕稼图》 |
| 山水 / 隐逸 | calligraphic ink on paper；干笔、层叠山石 | 赵孟頫、黄公望、吴镇、王蒙 |

## 服饰、建筑与器物

- 服饰与发式：蒙古人物可用交叠长袍、腰带、皮靴、软帽或皮帽；汉地人物保留交领或圆领袍与头巾。根据人物身份使用一种体系，不要混成清代服装。
- 建筑与基础设施：草原使用毡帐、木车和简易围栏；大都使用规划街道、木构与砖木建筑；江南使用水村、桥梁和瓦屋。
- 交通与日常器物：矮壮蒙古马、驮马、骆驼、牛车、木轮车、弓袋、马具、行囊和驿站旗帜。
- 文字与招牌：文字保持少量；需要官方凭证时可使用牌符意象，不生成醒目的伪八思巴文。

## 语义替换表

| 现代功能或元素 | 时代对应物（英文提示词用） | 选择条件 |
|---|---|---|
| 摩托车 / 越野车 | sturdy Mongol horse with period saddle and tack | 保留骑手位置、朝向和速度感 |
| 头盔 / 骑行服 | soft riding cap or fur-trimmed hat, belted Mongol robe, leather boots | 非战斗场景不加铠甲 |
| 公路与路标 | grass track, imperial post road, stone cairn, or station banner | 保留道路方向 |
| 房车 / 营地 | felt ger tents, baggage carts, tethered horses | 草原场景 |
| 汽车 / 卡车 | horse caravan, baggage wagon, ox cart | 按载人与载货功能选择 |
| 手机 / GPS | route scroll, tally, paiza-like travel token, or remove | 依据导航或身份凭证功能选择 |

## 禁用与易混元素

- 禁止清代长辫、马褂、旗装和晚清军服；禁止俄式哥萨克、维京或奇幻游牧造型。
- 禁止把所有蒙古人物画成成吉思汗式铠甲武士。
- 江南元代山水不要加入草原毡帐；草原纪实场景不要强行套用黄公望式抽象山水。
