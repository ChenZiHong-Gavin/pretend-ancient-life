# 撒哈拉以南非洲历史分期 Catalog

禁止使用 `African tribal` 或单一“非洲古代”风格。先定位西非萨赫勒、几内亚湾、东非、埃塞俄比亚高地、中部或南部非洲，再确认具体社会。

本表只负责分期，不直接定义画风。所有现有条目仍是 `catalogued`：必须优先研究相关社群与当地机构提供的同时代雕塑、金属艺术、建筑、手稿、壁画、纺织或其他视觉传统，并区分礼仪 / 宫廷物件与日常生活；证据不足时不得编造统一“非洲古画”。

|---|---:|---|---|---|

## 使用规则

- 无独立参考时至少核对一项考古 / 博物馆资料和一项当地历史来源。
- 资料经常偏向宫廷、宗教或可保存材质；不要把缺少纺织品证据误当作当地不使用纺织品。
- 殖民前、接触期和殖民期必须分开；不要让欧洲物件提前出现。
