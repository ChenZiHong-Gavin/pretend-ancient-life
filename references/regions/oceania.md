# 大洋洲历史分期 Catalog

大洋洲不能按欧洲式王朝年表统一处理。先确定岛群、具体岛屿 / 社群、接触前后和证据类型。

本表只负责分期，不直接定义画风。所有现有条目仍是 `catalogued`：必须优先使用相关社群与当地文化机构的知识，分别研究雕刻、纺织、身体艺术、建筑、器物、岩画或其他适当视觉传统；不得把神圣 / 受限图像当作通用装饰，也不得编造统一“波利尼西亚风”。

## 使用规则

- 涉及仍延续的原住民文化时，优先使用该社群、当地博物馆或文化机构的自称和资料。
- 不把仪式物件自动放入普通日常生活，也不把十九至二十世纪民族志照片直接投射到更早时期。
- 用户只说“古代波利尼西亚”时，至少询问岛群和大致世纪。
